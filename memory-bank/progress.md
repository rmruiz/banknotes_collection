# Progress: Banknotes Collection

## What Works
- **Data Structure:** JSON-based cataloging system is established.
- **Infrastructure:** Directory structure for originals, full images, and flags is defined.
- **Web Frontend:** Basic static site structure with JS logic exists.
- **Tooling:** Python scripts for serving the web app, generating images, and generating PDFs are available.

## What's Left to Build / Improve
- **Automation:** Refine the AI extraction scripts for better accuracy.
- **UI/UX:** Enhance the `index.html` for better filtering and visualization.
- **Verification:** Implement a more robust system for marking banknotes as "verified".
- **Data Enrichment:** Expand the `_json/` metadata for more countries and banknotes.

## Current Status
- **Initialization Phase:** The project has a working foundation and is now being documented via the Memory Bank.

## Known Issues
- Dependency on ImageMagick being installed on the host system.
- Reliance on Ollama being active for AI-based scripts to function.
